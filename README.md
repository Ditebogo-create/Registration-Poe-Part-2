# Registration - PROG5121 Part 2

## Description
This project is a Java console application for user registration, login and messaging. 
Users can register with a valid username and password, log in, and send messages. 
Messages are stored in JSON format.

## Features
- User Registration with username and password validation
- User Login with validation checks
- Send Messages with unique Message ID
- Message Hash generation
- Store messages in JSON file
- Unit Tests for Login and Message classes

## Technologies Used
- Java
- NetBeans / VS Code
- JUnit for testing
- JSON for message storage
- GitHub for version control

## How To Run
1. Clone this repository
2. Open the project in NetBeans
3. Run the Main / login.java file
4. Follow the prompts to Register, Login and Send Messages

## Project Structure
- src/main/java - Contains registration.java , login.java and message.java
- src/test/java - Contains loginIT.java, messageIT.java
